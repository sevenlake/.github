# Sevenlake — Metadata-driven Business Applications

Sevenlake lets developers and implementation partners create reusable
business applications, modules and integrations using metadata.

## Current status — October 2026

Business Foundation and CRM are available in the trial environment.
Development continues on additional business modules and platform capabilities.

We are preparing the runtime and selected modules for open-source publication.
The public repositories currently contain our profile and roadmap;
runtime source is not yet published here.

## Runtime and Designer Studio

The runtime is intended for cloud and on-premises installations.
Developers can edit metadata files directly.

Designer Studio is proprietary and hosted by Sevenlake.
On-premises installations connect to it through an API.

Our planned Studio offer is 12 months free from account activation,
then £25 per developer per month or £250 per year.
One subscription covers work across multiple client installations.
AI usage is separate.
