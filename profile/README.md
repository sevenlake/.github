# Sevenlake

Sevenlake is an open-source project building a metadata-driven platform for adaptable business software.

Instead of repeatedly coding the same business functionality, Sevenlake aims to let developers and partners create reusable applications, modules and integrations that can be customised with AI.

## Current status

Sevenlake is in early development. We are publishing the roadmap and opening the project progressively as its foundations take shape.
